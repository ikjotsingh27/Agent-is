Pilot
Features Safety Go Online
100% Python Standard Library · Local-First · Free to Run

Your own always-on AI agent, with its own workspace and terminal.

Pilot runs privately on your computer (or in your own cloud container later), thinks through your API key, shows every step live, asks before risky actions, and connects to Telegram, Gmail, Google Calendar, and Discord.

Saved only in this browser. Start Pilot on your PC with python -m src window (or python -m src web --tunnel) and click Put online (free HTTPS link) in Settings.

Everything inside Pilot

Isolated Environment

Own Workspace, Python & Terminal

5 GB workspace folder, 2 GB RAM cap and 2-minute timeout per command, optional isolated Python venv, headless browser, and a live Web Terminal & file manager.

Chat, Files & Voice

Two-Way Files, PDFs & Voice Notes

Send any file or record a voice note with one click. Pilot natively reads PDF, Word, Excel, and PowerPoint, creates clean PDFs, and shows live step-by-step thinking.

Guided Connectors

Telegram, Gmail, Calendar & Discord

Built-in step-by-step setup and live Green / Yellow / Red health checks. Each connector stays narrowly scoped and loads tools only when switched on.

Safety & Approvals

Approve Cards & Second Check

Risky commands and outgoing emails wait for Approve or Deny with a separate second-check warning for deletes, personal folders, or brand-new email addresses.

Low Token Cost

388-Token Baseline & Quiet Runs

Lazy tool loading, cheap-model routing for easy chats, 6-turn rolling context, lazy skills, daily token & dollar caps, and quiet scheduled checks.

Full Control

Memory, Activity & Pause All

Plain editable Markdown memory notes, searchable Activity log with daily summaries, live RAM/CPU/GPU/disk dashboard, and one big red Pause All button.

Privacy & trust by design

Keys stay on your machine

API keys and connector secrets live only in local data/settings.json (git-ignored) and are redacted from chat, logs, and error messages.

Never-allowed guardrails

Reading saved browser/Windows passwords, reading Pilot's keys, disabling Windows security, and moving money or trading are always blocked.

Password-protected web access

Salted PBKDF2-SHA256 password hashing (200k rounds), brute-force lockout, HttpOnly SameSite=Strict Secure cookies, and CSRF header checks.

How to run online for $0 (and upgrade to a domain later)

Start Pilot on your PC

Open Pilot (python -m src window) and turn on Web access in Settings with a strong password.

Click "Put online"

Press Put online (free HTTPS link) to launch a free Cloudflare HTTPS Tunnel — no router ports or monthly server bill.

Access from anywhere

Paste your HTTPS link into the box at the top of this GitHub Pages site from your phone, laptop, or tablet.

Add a domain & cloud later

When you're ready, connect your custom domain to a named Cloudflare Tunnel or deploy the included Dockerfile to Railway / Render.
